# Отчёт по проекту PyQt6 Chat (home task from 21.10)

## 1. Внесённые изменения
- Добавлена обработка потери соединения с сервером в `ReceiveThread`.
- Реализован корректный выход из `SendThread` при закрытии приложения.
- Добавлен индикатор состояния подключения: `Connected` и `Disconnected`.
- Для взаимодействия между потоками и интерфейсом используются сигналы и слоты PyQt6.

## 2. Обработка потери соединения
`ReceiveThread` отслеживает получение сообщений от сервера. Если соединение закрывается или возникает ошибка сокета, поток отправляет сигнал `disconnected`. Обработчик `handle_disconnect()` обновляет индикатор на `Disconnected` и выводит предупреждение пользователю.

## 3. Остановка SendThread
Для завершения потока используется специальное значение `None`, помещаемое в очередь методом `stop()`. Поток получает это значение и завершает цикл. При закрытии окна вызывается `closeEvent()`, который останавливает `SendThread` и ожидает его завершения с помощью `wait()`.

## 4. Состояние подключения
- `Connected to ...` — соединение с сервером установлено.
- `Disconnected` — соединение потеряно или закрыто.

- Проверено отображение предупреждения при отключении сервера.
- Проверена остановка `SendThread` при закрытии окна.
- Проверено завершение потока после получения `None` из очереди.
