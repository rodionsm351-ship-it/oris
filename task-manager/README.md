# Трекер задач

Простое desktop-приложение для создания и просмотра задач. Проект написан на Python с использованием PyQt6.

## Возможности

- Создание задачи с названием и описанием.
- Выбор приоритета: Low, Medium или High.
- Отметки Important и Favorite.
- Просмотр списка созданных задач и их количество.
- Очистка формы без удаления уже созданных задач.
- Удаление последней задачи из списка.

## Требования

- Python 3
- PyQt6

Установить PyQt6 командой:

```bash
pip install PyQt6
```

## Запуск

Сохраните код приложения в файл `main.py`, откройте терминал в папке проекта и выполните:

```bash
python main.py
```

## Хранение данных

Задачи хранятся в памяти во время работы приложения. После закрытия программы список задач не сохраняется.
