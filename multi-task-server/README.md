# Многопоточный сервер задач (To-Do List)

Клиент-серверное консольное приложение на Python для управления общим списком задач

## 1. Как запустить проект

1. Запустите серверное приложение:
   ```bash
   python3 server.py

2. В отдельных окнах терминала запустите одного или нескольких клиентов:
    ```bash
    python3 client.py

## 2. Поддерживаемые команды

- /add <текст> — добавить новую задачу в список
- /list — вывести все текущие задачи
- /done <номер> — отметить задачу под указанным номером как выполненную
- /delete <номер> — удалить задачу под указанным номером
- /quit — корректно завершить работу клиента

## 3. Одновременная работа нескольких клиентов

Многопользовательская работа реализована на стороне сервера с помощью модуля threading:
- Главный поток сервера находится в бесконечном цикле ожидания подключений server.accept().
- При подключении каждого нового клиента создается отдельный поток threading.Thread(target=handle_client, args=(conn, addr), daemon=True).
- Все сетевые обмены с конкретным клиентом происходят внутри его персонального потока, благодаря чему главный поток сервера не блокируется и может мгновенно принимать новых пользователей.

## 4. Синхронизация доступа к общим данным

Все клиентские потоки сервера работают с единственным общим списком задач tasks = []

Cоздан объект блокировки tasks_lock = threading.Lock(). Контекстный менеджер with tasks_lock: оборачивает все операции чтения и модификации списка:
- Добавление задачи (tasks.append)
- Чтение списка для формирования ответа
- Изменение статуса задачи (tasks[idx]["done"] = True)
- Удаление задачи (tasks.pop)

Блокировка предотвращает состояние гонки. Если два клиента одновременно попытаются изменить список или один клиент будет читать его во время удаления другим, Lock гарантирует, что в каждый момент времени со списком работает строго один поток. Это защищает данные от искажения и предотвращает ошибки при работе программы
