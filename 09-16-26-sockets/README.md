# Чат-сервер на сокетах

## Формат заголовка сообщений
Для разделения потока TCP используется собственный бинарный протокол: `COMMAND + LENGTH + DATA`.
Заголовок состоит строго из 8 байт:
- **Команда (4 байта):** Строка в кодировке UTF-8, дополненная пробелами до 4 символов.
- **Длина payload (4 байта):** Целое число без знака (unsigned int), упакованное через `struct.pack` (формат `!I`).
Сразу после заголовка идут сырые данные (payload) указанной длины.

## Поддерживаемые команды
* `JOIN` — регистрация клиента под указанным именем на сервере.
* `TEXT` — текстовое сообщение (сервер рассылает его всем (broadcast), клиент выводит в консоль).
* `LIST` — запрос на получение списка всех подключенных пользователей.
* `QUIT` — запрос на корректное завершение соединения.
* `ERR ` — отправляется сервером клиенту при получении неизвестной команды.
