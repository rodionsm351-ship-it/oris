GearCatalog

Веб сервис для поиска оборудования для съемки.

Сделано:
- базовый интерфейс на html (главная страница, страница с описанием вещи, страница для создания, страница для изменения)
- запросы на создание оборудования

- редактирование данных
- поиск, фильтрация и сортировка
- хранение данных в json


Для запуска перейдите в папку ../flask_app и запустите файл app.py

В созданом data.json есть 3 тестовые записи, чтобы проверить поиск, фильтрацию и сортировку.
